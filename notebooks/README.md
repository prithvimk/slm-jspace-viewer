# Colab notebooks

Open the notebooks in numerical order. Once this feature branch is pushed, use
the `Open in Colab` URL pattern below, replacing the notebook path as needed:

`https://colab.research.google.com/github/prithvimk/slm-jspace-viewer/blob/feature/colab-jspace-tutorial/notebooks/<notebook>.ipynb`

Notebooks 1–3 are designed for anonymous use. Notebook 4 contains an optional,
user-controlled Hugging Face login only for the gated Gemma comparison.
